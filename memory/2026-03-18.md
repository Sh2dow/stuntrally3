### Problem 2: FixupBundle.cmake Error
- Error: `include could not find requested file: D:/Repos/Games/OTHER GAMES/stuntrally3/build/CMake/ConanBinDirs.cmake`
- Root cause: CMake was interpreting the relative path `${CMAKE_SOURCE_DIR}/CMake/ConanBinDirs.cmake` incorrectly
- Fix: Changed `include(${CMAKE_SOURCE_DIR}/CMake/ConanBinDirs.cmake)` to `include("D:/Repos/Games/OTHER GAMES/stuntrally3/CMake/ConanBinDirs.cmake")` using absolute path
- Location: `D:\Repos\Games\OTHER GAMES\stuntrally3\CMake\FixupBundle.cmake`

### Problem 3: File Locking Issues
- Issue: `cmake_pch.pch` file being locked by MSVC compiler processes
- Fix: Updated `build.ps1` to include retry loop for removing build directory (5 retries with 2 second delays)
- Added `taskkill` commands to kill compiler processes before build

### Problem 4: DLL Copy Errors in build.ps1
- Original script tried to copy DLLs from `bin/Release` to `bin/Release` (redundant)
- Fix: Updated copy logic to handle cases where files already exist and use `-ErrorAction Continue`
